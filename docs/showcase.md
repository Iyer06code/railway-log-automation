

## Project title
Railway Testing Log Automation with Google Sheets and Apps Script

## Short description
A spreadsheet-based workflow that automates recurring testing-log administration, organizes records by day and month, and provides an administrative interface for permitted corrections.

## Problem
Recurring operational logs can require repetitive manual work to prepare daily records, keep monthly records organized, and maintain historical entries.

## Solution
A Google Sheets and Google Apps Script workflow was implemented to support daily rollover, monthly sheet organization, shift handling, sign-in/sign-out, historical-sheet protections, and a dedicated administrative editing interface.

## Key features
- Daily rollover and archiving
- Month-specific record organization
- Historical period protection and admin editing
- Shift management
- Sign-in / sign-out flow
- Admin Tool / Data Editor
- Role-aware interface and workflow
